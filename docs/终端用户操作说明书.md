## 1. 快速开始

### 1.1 访问系统

1. 启动 XAgent 服务后，在浏览器地址栏输入：`http://<主机IP>:18080`
2. 推荐使用 **Chrome / Edge** 最新版浏览器
3. 系统支持桌面端、平板、手机自适应访问

### 1.2 登录

登录页面分为左右两部分：左侧为登录表单，右侧为品牌背景图。

1. 在「用户名」输入框中填入账号
2. 在「密码」输入框中填入密码（可点击右侧眼睛图标切换明文/密文）
3. 可在表单右下方切换界面语言：**简体中文 / English / 繁體中文**
4. 点击「登 录」按钮，或直接按 `Enter` 键提交

**登录后**：
- 默认跳转到「监控面板」
- 若直接访问受限页面，登录成功后会回跳到原目标页面
- 页面底部可点击「关于我们」查看软件版本、UI 版本、后端版本信息

> 💡 **首次部署**：系统启动时会自动创建默认管理员账号，请向系统部署人员索取初始用户名/密码，并在首次登录后尽快修改密码。

### 1.3 退出登录

点击页面右上角用户头像，在弹出菜单中选择「退出登录」即可。

### 1.4 五分钟上手流程

```
登录 → 添加设备（设备管理）→ 添加通道（通道管理）
     → 创建规则（规则引擎，可选）→ 配置告警（告警配置，可选）
     → 制作组态画面（项目管理，可选）→ 在监控面板观察运行情况
```

## 3. 监控面板（Dashboard）

监控面板是登录后的默认首页，提供系统整体运行总览。

### 3.1 顶部统计卡片

| 卡片 | 含义 | 状态判断 |
| --- | --- | --- |
| 待处理告警 | 当前未确认的告警数 | 有数字即需关注 |
| 在线设备 | 在线设备数 / 总设备数 | 运行良好 / 部分离线 / 多数离线 |
| 在线通道 | 在线通道数 / 总通道数 | 连接正常 / 部分断开 / 多数断开 |
| 活跃规则 | 启用状态的规则数 | 启用 / 无规则 |

### 3.2 系统资源

显示当前主机的 **CPU / 内存 / 磁盘** 使用率，负载较高时会高亮提示。

### 3.3 通道上传统计

- **总上传速率**：所有北向通道每秒上行数据条数
- **平均成功率**：上行成功比例
- **数据积压**：尚未发出的缓冲数据量
- 状态：传输良好 / 需要关注

### 3.4 数据采集趋势

折线图展示采集总量随时间变化，支持切换时间范围：**1小时 / 24小时 / 7天**，并显示峰值与均值。

### 3.5 最新告警

显示最近触发的告警列表，点击「查看全部」可跳转告警配置页。

### 3.6 系统信息

| 指标 | 含义 |
| --- | --- |
| 运行时长 | 服务连续运行时间 |
| 采集总量 | 累计采集数据条数 |
| 今日采集 | 当日采集数据条数 |
| 数据质量 | good / bad / uncertain 比例 |

### 3.7 刷新数据

点击右上角「刷新数据」按钮可手动刷新所有面板数据，页面也会定期自动刷新。

## 4. 设备管理

设备管理用于配置现场设备的连接参数与采集点位，是数据接入的核心模块。

### 4.1 设备列表

进入「设备管理」后，默认显示设备列表视图。

**顶部工具栏**：
- 🔍 搜索框：按设备名称/资产标识模糊搜索
- 状态筛选：全部 / 在线 / 离线
- 「新增设备」：打开新增设备弹框
- 「刷新」：重新加载列表
- 「导入」/「导出」：批量配置迁移

**设备卡片信息**：
- 设备名称、资产标识、协议类型
- 在线/离线状态徽标
- 主机地址、端口
- 点位数量
- 操作按钮：编辑、删除、热重载、启用/禁用切换

### 4.2 新增设备

点击「新增设备」打开配置弹框，按以下步骤填写：

#### 第一步：基本信息

| 字段 | 说明 |
| --- | --- |
| 资产标识 | 唯一标识，仅允许字母、数字、下划线、连字符 |
| 设备名称 | 可读名称，留空则使用资产标识 |
| 描述 | 设备用途备注 |
| 协议类型 | Modbus TCP / Modbus RTU / KNX / BACnet |
| 启用 | 是否启用此设备 |

#### 第二步：协议配置（按协议不同）

**Modbus TCP**：
- 主机地址（如 `192.168.1.100`）
- 端口（默认 502）
- 从站 ID
- 采集周期（秒，推荐 1-5 秒）
- 超时（秒）

**Modbus RTU**：
- 串口（如 `COM3` 或 `/dev/ttyUSB0`）
- 波特率、数据位、停止位、校验位
- 从站 ID、采集周期、超时

**KNX**：
- 网关 IP、端口（默认 3671）
- 本地 IP（多网卡时指定）
- 连接模式：自动（推荐）/ UDP 隧道 / TCP 隧道 / 路由 / 安全 TCP 隧道 / 安全路由
  > 💡 网关连接数满时改用「路由模式」
- 同步模式：智能（推荐）/ 主动 / 被动
- 同步间隔（分钟，默认 60）
- 采集周期

**BACnet**：
- 主机地址、端口（默认 47808）
- 设备 ID
- 采集周期（推荐 5-10 秒）
- 超时

#### 第三步：标签（可选）

填写标签（多个用逗号分隔，如 `厂房1,温度`），便于后续筛选与分组。

点击「确定」保存设备。

### 4.3 配置点位

1. 在设备列表中点击目标设备，进入点位列表视图
2. 点击「添加点位」打开点位配置弹框

**通用配置**：

| 字段 | 说明 |
| --- | --- |
| 点位名称 | 仅允许字母、数字、下划线、连字符、中文 |
| 描述 | 点位用途说明 |
| 数据类型 | 协议相关（见下方） |
| 标准类型 | 自动推导，无需手动设置 |
| 单位 | 如 °C、%、V、A |
| 最小值/最大值 | 量程范围（可选） |
| 高报警/低报警 | 阈值（可选） |
| 标签 | 多个用逗号分隔 |

**协议特定配置**：

- **Modbus**：寄存器类型（保持/输入/线圈/离散输入）、寄存器地址、寄存器数量、字节顺序、字顺序、缩放因子、偏移量
  - 数据类型：uint16 / int16 / uint32 / int32 / float32 / float32_swap / float64 / uint64 / int64 / bool / string
- **KNX**：组地址（如 `1/2/3`）、状态地址、控制地址、可写
  - 数据类型：switch / bool / percent / brightness / temperature / humidity / co2 / voltage / power 等
- **BACnet**：对象类型（analogInput/analogOutput/binaryInput 等）、对象实例、属性（默认 presentValue）

### 4.4 点位操作

在点位列表中，每个点位行提供以下操作：

| 按钮 | 功能 |
| --- | --- |
| 📈 趋势 | 打开点位趋势图，查看历史数据曲线 |
| ✏️ 编辑 | 修改点位配置 |
| 🗑 删除 | 删除点位（需确认） |
| ✍ 写值 | 对可写点位下发控制值（见 4.5） |

**点位趋势图**功能：
- 时间范围：6小时 / 自定义
- 聚合粒度：1分钟 / 5分钟 / 15分钟 / 1小时
- 自动刷新（可配置刷新间隔）
- 显示上下限、平均线、数据点（可开关）
- 模拟量/数字量不同展示方式（数字量显示开启次数、开启率）

### 4.5 写入点位值

1. 点击点位的「写值」按钮，打开写值弹框
2. 弹框显示：设备名、点位名、当前值
3. 在「目标值」中输入要写入的数值（布尔点位显示「开/关」开关）
4. 点击「确认写入」下发命令

> ⚠️ **注意**：写值操作会直接下发到现场设备，请确认写入值在合理范围内，避免造成设备损坏或工艺异常。

### 4.6 设备发现（BACnet 专用）

针对 BACnet 协议，系统提供自动发现功能：

1. 在新增设备弹框中选择协议为 BACnet
2. 点击「发现设备」按钮
3. 选择本机网卡（多网卡环境需指定）
4. 系统广播 Who-Is，等待设备响应 I-Am（总超时 60 秒）
5. 在返回列表中勾选要导入的设备
6. 可对已添加的 BACnet 设备执行「发现点位」，自动读取对象列表与属性并批量导入

### 4.7 热重载

修改设备或点位配置后，无需重启服务：

- **单设备热重载**：点击设备卡片上的「热重载」按钮
- **批量热重载**：在设备列表页点击工具栏的批量重载按钮

热重载会重新加载插件实例并应用新配置，期间该设备会有短暂采集中断。

### 4.8 设备导入导出

- **导出**：可勾选多个设备导出为 YAML 文件，便于备份或迁移
- **导入**：选择 YAML 文件后弹出确认框（显示将导入的设备数），确认后执行批量导入
- 导入支持覆盖模式，重复资产标识会被更新

## 5. 通道管理

通道管理用于配置北向数据上行通道，将采集的设备数据转发到云端或上位机平台。

### 5.1 通道列表

**顶部工具栏**：
- 搜索框、状态筛选（全部/在线/离线）、协议筛选（全部/MQTT/XNC/HTTP）
- 「新增通道」、「刷新」、「导入」、「导出」

**通道卡片信息**：
- 通道 ID、名称、描述
- 协议类型（MQTT/XNC/HTTP）
- 适配器类型（标准/C001）
- 在线/离线状态
- 操作：编辑、删除、启用/禁用、测试连接、重启

### 5.2 新增通道

#### 第一步：基本信息

| 字段 | 说明 |
| --- | --- |
| 通道 ID | 唯一标识 |
| 通道名称 | 可读名称 |
| 描述 | 通道用途 |
| 协议类型 | MQTT / XNC / HTTP |
| 启用 | 是否启用 |

#### 第二步：连接配置（按协议不同）

**MQTT 通道**：
- 主机地址、端口
- 用户名、密码
- 客户端 ID（可留空自动生成）
- 主题（数据上行）、命令主题（下行订阅）
- QoS（0/1/2）、保活时间、清洁会话
- 适配器：标准 / C001（客户A私有云协议）
- 适配器配置：JSON 格式
- 发布模式：单次发送 / 批量发送
- 命令超时（秒）

**XNC 通道**：
- 远程主机、远程端口、本地端口
- 重连间隔
- 映射配置、产品 Key

**HTTP 通道**：
- 端点 URL、请求方法（GET/POST/PUT/DELETE）
- 请求头、超时时间
- 立即上传/批量上传、批量大小、上传间隔
- 重试次数、重试间隔

#### 第三步：标签（可选）

点击「确定」保存通道。

### 5.3 通道操作

| 操作 | 说明 |
| --- | --- |
| 编辑 | 修改通道配置 |
| 删除 | 删除通道（需确认） |
| 启用/禁用 | 切换通道运行状态 |
| 测试连接 | 验证通道连通性（不保存配置） |
| 重启 | 重启通道插件实例 |

### 5.4 通道详情

点击通道卡片进入详情视图，显示：
- 总上传量
- 上传速率（条/分钟）
- 成功率
- 数据积压

### 5.5 适配器说明

| 适配器 | 用途 |
| --- | --- |
| 标准适配器 | 默认数据格式，通用场景 |
| C001（客户A） | 客户A私有云协议，需配合产品 Key 使用 |

适配器的详细配置（收件人、SMTP、Webhook 等）需根据适配器类型填写对应 JSON。

## 6. 规则引擎

规则引擎用于实现场景联动、告警触发、定时任务等业务逻辑，采用可视化节点画布编辑。

### 6.1 规则列表

**顶部工具栏**：
- 搜索框、类型筛选（全部/场景联动/告警规则/定时任务）
- 「新建规则」、「导入」、「导出」、「刷新」

**规则卡片信息**：
- 规则名称、描述
- 类型标签（场景/告警/定时）
- 执行次数、最后触发时间
- 操作：编辑、复制、启用/禁用、删除

### 6.2 规则类型

| 类型 | 用途 | 典型场景 |
| --- | --- | --- |
| 场景联动 | 设备状态触发另一设备动作 | 温度高→开风机 |
| 告警规则 | 数据越限触发通知 | 温度>30°C→发邮件 |
| 定时任务 | 按时间表触发动作 | 每天 8:00 开灯 |

### 6.3 规则编辑器

点击「新建规则」或「编辑」进入规则编辑器，采用可视化节点画布：

#### 界面布局

```
┌──────────────┬───────────────────────────┬──────────────┐
│  节点面板    │       画布区域             │  节点配置    │
│  (拖拽源)    │   (拖入节点、连线)         │   面板       │
│              │                           │              │
│ ▸ 触发器     │   [触发]→[条件]→[动作]    │ 字段配置区   │
│ ▸ 条件       │                           │              │
│ ▸ 逻辑       │                           │              │
│ ▸ 动作       │                           │              │
│ ▸ 通知       │                           │              │
└──────────────┴───────────────────────────┴──────────────┘
```

#### 节点类型

| 节点 | 分类 | 作用 |
| --- | --- | --- |
| 🎯 数据触发器 | 触发器 | 监听某设备某点位数据变化 |
| ⏰ 定时触发器 | 触发器 | 按时间表触发（一次性/周期性/Cron） |
| ⚙ 条件判断 | 条件 | 判断字段是否满足比较条件 |
| 🔀 逻辑运算 | 逻辑 | AND / OR / NOT 组合多条件 |
| ⚡ 执行动作 | 动作 | 向目标设备下发命令 |
| 📢 通知告警 | 通知 | 通过渠道发送告警通知 |

#### 编辑流程

1. **拖入节点**：从左侧节点面板拖拽节点到画布
2. **连线**：鼠标悬停节点边缘出现连接点，拖拽到下一节点建立连线
3. **配置节点**：点击节点选中，在右侧配置面板填写参数
4. **删除节点**：选中节点后点击删除按钮，或按 `Delete` 键
5. **保存规则**：点击右上角「保存」按钮

#### 节点配置详解

**🎯 数据触发器**：
- 数据源设备（下拉选择）
- 数据点位（下拉选择）
- 南向插件（自动带出）

**⏰ 定时触发器**：
- 模式：一次性 / 周期性 / Cron 表达式
- 周期性：每天 / 每周 / 每月 + 执行时间
- 一次性：执行日期 + 执行时间
- Cron：格式「秒 分 时 日 月 周」（如 `0 0 8 * * *` 每天 8 点）
- 生效日期范围：开始日期 ~ 结束日期

**⚙ 条件判断**：
- 字段名（选择或输入）
- 运算符：大于/小于/大于等于/小于等于/等于/不等于/正则匹配
- 比较值
- 持续时间（秒，0 = 即时触发）

**🔀 逻辑运算**：
- 逻辑运算符：AND（所有条件都满足）/ OR（任一条件满足）/ NOT（条件不满足）

**⚡ 执行动作**：
- 目标设备
- 操作类型：写入设定值 / 执行操作
- 写入点位、写入值
- 延迟执行（秒，0 = 立即执行）

**📢 通知告警**：
- 告警级别：提示 / 警告 / 错误 / 紧急
- 通知渠道：系统通知 / 邮件 / Webhook
  > 💡 渠道的详细配置（收件人、SMTP、Webhook URL 等）请在「告警配置」页面统一管理

### 6.4 保存校验

点击「保存」时系统会自动校验：
- 规则名称不能为空
- 画布不能为空
- 必须包含触发器节点
- 必须包含执行动作或通知告警节点
- 节点之间必须有连线
- 各节点必填字段不能为空

校验不通过会弹出提示框，列出所有未完善项。

### 6.5 规则管理

| 操作 | 说明 |
| --- | --- |
| 编辑 | 进入编辑器修改规则 |
| 复制 | 基于现有规则快速复制一份 |
| 启用/禁用 | 切换规则是否生效 |
| 删除 | 删除规则（需确认） |
| 导入/导出 | 批量迁移规则配置 |

## 7. 告警配置

告警配置页面包含两个 Tab：**告警记录** 与 **通知渠道**。

### 7.1 告警记录

#### 7.1.1 列表与筛选

- 🔍 搜索框：按告警消息模糊搜索
- 级别筛选：紧急 / 警告 / 提示
- 状态筛选：新建 / 已确认 / 已解决 / 已忽略
- 「刷新」、「清除已解决」按钮

#### 7.1.2 告警状态流转

```
新建（new） ──确认──→ 已确认（acknowledged） ──解决──→ 已解决（resolved）
                    └──忽略──→ 已忽略（ignored）
```

#### 7.1.3 告警操作

每条告警记录显示：告警规则、告警信息、级别、状态、触发时间。

| 按钮 | 功能 |
| --- | --- |
| 确认 | 标记为已确认（表示已知晓） |
| 解决 | 标记为已解决 |
| 忽略 | 暂时忽略此告警 |

「清除已解决」会一键清除所有已解决状态的告警记录。

### 7.2 通知渠道

通知渠道用于配置告警通知的发送方式，支持三类渠道。

#### 7.2.1 系统通知

站内通知，无需外部依赖。

**配置项**：
- 保留天数：告警记录保留天数
- 最大通知数：超出上限自动清除最早通知
- 通知级别：勾选要通知的级别（紧急/警告/提示）
- 桌面通知：通过浏览器推送桌面弹窗（需授权）
- 提示音：收到新通知时播放声音
- 免打扰模式：设定时段内不发送桌面通知和提示音（开始时间 ~ 结束时间）
- 自动已读：通知发出后多少分钟自动标记为已读（0 = 不自动）

#### 7.2.2 邮件通知

通过 SMTP 发送告警邮件。

**配置项**：
- SMTP 服务器地址、端口
- 启用 STARTTLS / 启用 SSL（SSL 通常用于端口 465）
- 用户名、密码
- 发件人地址
- 收件人列表：输入邮箱地址后按回车添加，可添加多个

#### 7.2.3 Webhook

通过 HTTP 请求推送告警到指定 URL。

**配置项**：
- Webhook URL
- 请求方法：POST / PUT / GET
- 自定义请求头
- 签名密钥：用于验证请求来源

#### 7.2.4 渠道操作

| 操作 | 说明 |
| --- | --- |
| 启用/禁用 | 切换渠道是否生效 |
| 配置 | 打开渠道配置弹框 |
| 测试 | 发送一条测试通知验证配置是否正确 |

> ⚠️ 测试前请先启用该渠道，禁用状态下无法测试。

## 10. 常用操作速查

### 10.1 接入一台新设备的完整流程

```
1. 设备管理 → 新增设备 → 填写基本信息与协议配置 → 确定
2. 进入设备详情 → 添加点位 → 填写点位配置 → 保存
3. （可选）热重载设备使配置立即生效
4. 监控面板 → 观察数据是否正常采集
5. （可选）项目管理 → 创建组态画面绑定该设备点位
```

### 10.2 接入一台新云端平台的流程

```
1. 通道管理 → 新增通道 → 选择协议（MQTT/XNC/HTTP）→ 填写连接配置
2. 点击「测试连接」验证连通性
3. 启用通道
4. 监控面板 → 查看通道上传统计，确认数据正常上行
```

### 10.3 配置一个高温告警的流程

```
1. 告警配置 → 通知渠道 Tab → 启用「邮件」→ 配置 SMTP → 测试
2. 规则引擎 → 新建规则 → 类型选「告警规则」
3. 拖入「数据触发器」→ 绑定温度点位
4. 拖入「条件判断」→ 温度 > 30，持续 60 秒
5. 拖入「通知告警」→ 级别「警告」，渠道「邮件」
6. 连线：触发器 → 条件 → 通知
7. 保存规则 → 启用规则
```

### 10.4 配置一个定时开关灯的流程

```
1. 规则引擎 → 新建规则 → 类型选「定时任务」
2. 拖入「定时触发器」→ 模式「周期性」→ 每天 08:00
3. 拖入「执行动作」→ 目标设备选灯控 → 写入点位选开关 → 写入值「开」
4. 连线并保存
5. 复制此规则，修改时间为 18:00、写入值为「关」
```

### 10.5 制作一个车间监控大屏的流程

```
1. 项目管理 → 新建项目 → 类型选「Dashboard」→ 设置画布尺寸
2. 从左侧拖入「仪表盘」「数值」「指示灯」等组件
3. 选中组件 → 右侧绑定设备点位 → 配置样式
4. 拖入「折线图」→ 绑定点位 → 配置时间范围
5. 上传车间平面图作为画布背景
6. 保存 → 预览验证
7. （可选）发布面板供他人查看
8. （可选）在项目列表配置幻灯片轮播
```

### 10.6 排查设备离线的流程

```
1. 监控面板 → 查看「在线设备」卡片，确认离线设备数
2. 设备管理 → 筛选「离线」→ 找到离线设备
3. 点击「编辑」→ 核对主机地址、端口、从站 ID 等连接参数
4. 点击「热重载」重新连接
5. 系统设置 → 日志 → 筛选 WARNING/ERROR → 查看错误详情
6. 若仍无法恢复，检查现场设备网络与电源
```

## 11. 常见问题

### 11.1 登录相关

**Q1：忘记密码怎么办？**
A：请联系系统管理员，在「系统设置 → 用户」中为您重置密码。管理员无法查看原密码，只能设置新密码。

**Q2：登录后看不到某些菜单？**
A：菜单根据角色权限显示。请联系管理员在「系统设置 → 权限」中为您的角色勾选对应资源的「查看」权限。

**Q3：账号被锁定怎么办？**
A：多次密码错误可能导致账号锁定（状态显示「锁定」）。请联系管理员在用户列表中将状态改回「活跃」。

### 11.2 设备相关

**Q4：设备一直显示离线？**
A：
1. 核对设备 IP、端口、从站 ID 是否正确
2. 确认主机与设备网络互通（可用 ping 测试）
3. 检查防火墙是否放行对应端口
4. 查看系统设置 → 日志中的错误信息
5. 尝试热重载设备

**Q5：点位数据质量显示「异常」或「不确定」？**
A：
- Modbus：检查寄存器地址、数量、数据类型、字节顺序是否与设备文档一致
- BACnet：检查对象类型与实例号是否正确
- KNX：检查组地址是否正确
- 查看日志获取具体通信错误

**Q6：写值操作失败？**
A：
1. 确认点位配置中「可写」已开启
2. 确认设备在线
3. 确认写入值在合理范围内（最小值/最大值）
4. 查看日志中的命令执行错误

**Q7：BACnet 设备发现找不到设备？**
A：
1. 确认主机与 BACnet 设备在同一广播域
2. 多网卡环境下选择正确的网卡
3. 设备发现总超时为 60 秒，可分多次小范围发现
4. 确认 BACnet 设备的 UDP 47808 端口未被占用

**Q8：KNX 网关提示连接数满？**
A：将连接模式改为「路由模式」，使用多播通信不占用连接槽（需 KNX 网络支持多播）。

### 11.3 通道相关

**Q9：MQTT 通道连接失败？**
A：
1. 核对 Broker 地址与端口
2. 确认用户名密码正确
3. 确认 Broker 已启用对应端口（非加密 1883 / SSL 8883）
4. 点击「测试连接」单独验证
5. 检查防火墙

**Q10：通道显示在线但数据不上行？**
A：
1. 检查主题是否正确
2. 检查适配器配置是否匹配
3. 查看监控面板「通道上传统计」的积压数
4. 进入通道详情查看上传速率与成功率

### 11.4 规则相关

**Q11：规则保存时提示校验失败？**
A：系统会列出所有未完善项，常见原因：
- 规则名称为空
- 缺少触发器节点
- 缺少动作或通知节点
- 节点未连线
- 节点必填字段未填（如触发器未绑定数据源、动作未选目标设备等）

按提示补全后重新保存。

**Q12：规则已启用但未触发？**
A：
1. 确认规则状态为「启用」
2. 确认触发器绑定的点位有数据更新
3. 条件判断的「持续时间」可能未满足
4. 在规则卡片查看「执行次数」「最后触发时间」判断是否生效
5. 查看日志排查规则引擎错误

**Q13：邮件通知收不到？**
A：
1. 在「告警配置 → 通知渠道」中点击「测试」单独验证
2. 确认 SMTP 端口与 TLS/SSL 配置匹配（587+STARTTLS / 465+SSL）
3. 检查发件邮箱是否开启 SMTP 授权
4. 查看收件人列表是否正确
5. 查看日志中的 SMTP 错误

### 11.5 组态画面相关

**Q14：组态画面预览时组件不显示数据？**
A：
1. 确认组件已绑定点位
2. 确认绑定的设备在线且点位有数据
3. 检查「系统设置 → 可视化 → 读值周期」设置
4. 刷新预览页面

**Q15：组态画面控制操作无效？**
A：
1. 确认绑定的点位「可写」已开启
2. 确认设备在线
3. 确认写入值在合理范围
4. 查看日志中的命令下发记录

**Q16：如何让组态画面在监控大屏轮播？**
A：
1. 在「项目管理」列表页点击「幻灯片配置」
2. 设置切换间隔、循环播放、切换效果、项目范围
3. 点击「预览所有」开始轮播
4. 大屏浏览器全屏显示即可

### 11.6 系统维护相关

**Q17：数据库文件越来越大？**
A：
1. 系统设置 → 通用 → 调小「数据保留」天数（如 1-7 天）
2. 等待下次清理任务自动执行
3. 或联系管理员通过 API 执行 VACUUM 压缩

**Q18：如何备份系统配置？**
A：系统设置 → 备份 → 点击「立即创建」生成备份，或点击「导出」下载配置文件到本地。

**Q19：日志级别如何临时调整用于排障？**
A：系统设置 → 通用 → 日志级别改为 DEBUG → 保存（立即生效）。排障完成后记得改回 INFO。

**Q20：如何切换深色主题？**
A：点击顶部头部的 🌓 主题切换图标，可在浅色/深色主题间切换，选择会自动保存。
